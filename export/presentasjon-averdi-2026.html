Sikkerhet

Sikker filoverlevering

Bygget for trygg deling av sensitive dokumenter mellom kunde og regnskapsforer. Eget .averdi-filformat med kryptering på militærnivå. Ingen eksterne avhengigheter. Alt skjer i nettleseren.
  • ✓ AES-256-GCM-kryptering
  • ✓ PBKDF2 nøkkelavledning (600 000 iterasjoner)
  • ✓ Per-fil salt mot forhands-beregningsangrep
  • ✓ 6-sifret PIN for enkel deling
  • ✓ Drag-and-drop filopplasting
  • ✓ Opptil 25 MB per fil
  • ✓ Null eksterne avhengigheter (Web Crypto API)
.averdi filformat
[6 bytes]   Magic: "AVRD01"
[4 bytes]   Metadata-lengde (uint32 BE)
[N bytes]   Metadata JSON (ukryptert)
[12 bytes] IV (96-bit for GCM)
[Rest]     Kryptert data + auth tag

Metadata inkluderer:
- Avsendernavn
- Organisasjonsnummer
- Tidsstempel
- Datatype (vipps-config, api-credentials, ...)
- Antall filer
- Beskrivelse
